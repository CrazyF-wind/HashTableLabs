# ES6 函数简写

对应文章：[ES6函数简写及思考](https://crazyf-wind.github.io/2019/09/26/ES6函数简写及思考/)

`index.js` 演示同一个函数的五种写法，以及 `Array.prototype.sort` 比较函数的简写。

## 运行

```bash
cd frontend/es6-shorthand
node index.js
node --test index.test.js
```

`node index.js` 的预期输出：

```
五种写法的结果： [ 8, 8, 8, 8, 8 ]
按 age 升序： [
  { name: '小红', age: 11 },
  { name: '小明', age: 12 },
  { name: '小华', age: 13 },
  { name: '小刚', age: 15 }
]
```
